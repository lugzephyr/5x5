# 5x5

Vite + React + TypeScript PWA. See `README.md` for stack and scripts.

## Working style

- Keep code and config clean, simple and minimal.
- Follow current official practices: check the latest docs and npm versions before adding or changing tooling.
- For tooling choices, give a recommendation with trade-offs and let the user decide.

## Workflow

- `main` is protected: never push to it. Branch off `main` (`feat/...`, `fix/...`), push, open a PR with `gh pr create`. The user reviews the Vercel preview and squash-merges.
- CI (`check` job) must pass: run `pnpm lint`, `pnpm format:check`, `pnpm test --run` and `pnpm build` before pushing.

## Deploy

- Vercel project `5x5`, production at https://5x5-omega.vercel.app. Every PR gets a preview URL.

## Notes

- `src/routeTree.gen.ts` is generated by the TanStack Router plugin and committed (the build type-checks before Vite runs). Don't edit it by hand.
- Add shadcn/ui components with `pnpm dlx shadcn@latest add <name>`.
